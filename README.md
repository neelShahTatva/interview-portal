## API Documentation and Maintenance

**Important:** Whenever an API is created, modified, or removed, the developer responsible for the change must ensure that all related API documentation is updated.

The following documentation sources must be kept up to date:

1. **Postman:** Update the relevant API requests, endpoints, request parameters, headers, and response examples.

2. **Swagger:** Update the API specifications, endpoint descriptions, request/response models, and annotations.

3. **Project Documentation:** Update the relevant API details and technical documentation to reflect the latest changes.

### Developer Responsibility

Maintaining consistency between the actual backend APIs, Postman collection, Swagger documentation, and project documentation is the responsibility of the developer making the API changes.

**All three documentation sources must reflect the latest API implementation whenever an API change is made.**
